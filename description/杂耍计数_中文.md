# 如果你喜欢本mod，也欢迎看看我的其它mod。或许对你有帮助。

## ① 效果

为铁甲战士的能力牌“杂耍”（Juggling）的 buff 图标右上角添加“本回合已打出攻击牌数”的计数，右下角原有的层数（复制次数）保持不变。

“杂耍”的效果是：复制玩家每回合打出的第 3 张攻击牌。本 mod 显示的正是“本回合已经打出了几张攻击牌”，防止玩家忘记距离触发复制还差几张。

计数显示真实数字（0、1、2、3……不封顶），回合切换后自动归零；即使先打出攻击牌再打出杂耍，计数也会从战斗全局变量历史中获得，显示正确的已打出的攻击牌数。

本 mod 为纯显示增强：不改变卡牌效果、不改变任何数值、不修改游戏机制。

## ② 影响（基于本人游戏理解）

“杂耍”的复制时机取决于本回合已打出的攻击牌数，但游戏本身并不会把这个数字直观地展示出来，玩家很容易忘掉“还差几张触发复制”。

本 mod 把这个数字直接显示在 buff 图标上，减少记忆负担，让玩家能把注意力放在更重要的决策上。

本 mod 不影响存档，关闭 mod 后一切恢复原状。

## ③ 环境与版本

本 mod 不依赖任何基础 mod。

本 mod 支持 default 0.107.x 与 public beta 0.111.0 及以上版本（两者均已实测通过）。

理论上只要没有大的 API 更新或杂耍卡牌机制修改，本 mod 无须修改即可自动适配新版本。

## ④ 实现方式与兼容性

本 mod 采用最小依赖的方式写成（纯 Harmony 补丁，零第三方库），正常来说与大多数 mod 兼容，且不易随着版本变化而失效。

本 mod 的计数数据直接来自游戏的战斗历史（与游戏内部“本回合已打出攻击牌数”的统计同源），显示值永远与游戏实际状态一致；

角标动态复制游戏原层数标签的样式（字体、字号、颜色、描边一致），仅将位置改为位于图标右上角。

本 mod 在不同游戏版本的生效方式均相同。

但本 mod 不保证与盗版、修改版、移动版、老旧版本或者冷门 mod、次级 mod 的兼容性。
