## 二、必须修正：打出者判定（卡牌易主）

v0.113 的 `CardPlay` 文档明确写道：`Player` 可能与 `Card.Owner` 不同，例如"球"（The Ball）打出后会换手；因此官方 `AfterApplied` 用 `e.CardPlay.Player`。

当前 mod 的谓词是 `e.CardPlay.Card.Owner.Creature == power.Owner`。它每次刷新都会重新读取 `Card.Owner`，于是：

- 铁甲玩家打出"球"（攻击牌）后，该牌被移交给另一名玩家；
- 下一次刷新时，这条历史记录的 `Card.Owner` 已变成另一名玩家；
- 铁甲的杂耍计数会少 1，另一名玩家（若也有杂耍）会多 1，与官方内部计数不一致。

修正：改用历史条目写入时快照的 `e.Actor`。`CardPlayStartedEntry` 的构造函数把 `cardPlay.Card.Owner.Creature` 存进基类 `Actor`，之后卡牌易主不会改变它；`Actor` 在 0.107/0.111/0.113 均存在，语义等于 0.111+ 的 `CardPlay.Player`。

```csharp
return combat.History.CardPlaysStarted.Count(e =>
    e.CardPlay.Card.Type == CardType.Attack &&
    e.Actor == power.Owner &&
    e.HappenedThisTurn(power.CombatState));
```

"球"在 0.107 尚不存在，因此该修改不改变 0.107 的显示结果；0.111/0.113 则与官方计数完全一致。

## 三、角标 1px 观感核对

### 3.1 布局本身是逐像素对齐的

- 角标由 `%AmountLabel` 复制而来，矩形同为 `x = -56 .. 44`（宽 100）、右对齐、同字体/字号/描边/阴影。
- 角标只改 y：`21..44` → `0..23`；x 与宽度不动。
- Godot 实测：复制后设置 `Position = (-56, 0)`，`Size` 仍为 `(100, 27)`（高度被 Label 最小尺寸撑开，原标签同样被撑开），两者右缘同为 `x = 44`。
- 结论：不存在系统性的 1px 偏移；同一数字上下两行渲染逐像素一致。

### 3.2 1px 来自数字轮廓与 UI 缩放

中文界面下 `MegaLabel._Ready` 会用 `NotoSansMonoCJKsc-Regular.otf` 替换主题字体。实测该字体 18px 时：

| 数字 | 步进（advance） | 右侧留白（RSB） |
|---|---|---|
| 0 | 9.000 px | 0.954 px |
| 1 | 9.000 px | 0.864 px |
| 2 | 9.000 px | 0.864 px |
| 3 | 9.000 px | 1.134 px |
| 4 | 9.000 px | 0.666 px |
| 5 | 9.000 px | 1.080 px |
| 6 | 9.000 px | 0.918 px |
| 7 | 9.000 px | 0.936 px |
| 8 | 9.000 px | 0.900 px |
| 9 | 9.000 px | 0.990 px |

等宽字体的步进相同，但每个数字的轮廓在字身框内并不对称，右侧留白最大差 0.468px。游戏基准分辨率为 1920×1080（`project.godot`），本机 2560×1440 窗口的 canvas 缩放约 1.333 倍，描边后的右缘差约 0.6px；落在不同的子像素相位时，栅格化后表现为 0–1px。

用同一字体、同一字号/描边、1.333 倍缩放渲染实测：同一相位下不同数字的最右墨迹列会相差 1 列（如整数相位下数字 3 为 `x=188`、其余为 `x=189`；0.25 相位下数字 4 为 `x=536`、其余为 `x=535`）；同一个数字上下两行完全重合。官方层数标签换数字时也有同样的摆动，这是字体轮廓 + 子像素相位的固有现象。

**结论：不是位置写错，也不是我们的角标特有；不需要改代码。** 若强行按"墨迹右缘"逐数字补偿，会让角标偏离官方标签的排版规则，不建议。

## 四、0.113 变更对 mod 的其他影响

- 0.113 的 `JugglingPower` 把复制动作从 `BeforeCardPlayed` 移到 `AfterCardPlayed`：只影响复制品出现的时机，不影响"本回合攻击牌数"。
- 0.113 的 `CardPlayStarted` 增加实时战斗守卫：回放/幽灵战斗不再写入历史，角标也不会被这些路径刷新，符合直觉。
- 0.113 的 `NPower` 悬停动画只缩放图标本身；官方层数标签同样不缩放，角标行为与官方一致。
- mod 不依赖本地化表，0.113 新增语言/表项无影响。
