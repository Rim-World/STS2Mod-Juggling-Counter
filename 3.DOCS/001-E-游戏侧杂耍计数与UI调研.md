### 1.2 能力 `MegaCrit.Sts2.Core.Models.Powers.JugglingPower`（完整反编译）

```csharp
public sealed class JugglingPower : PowerModel
{
    private class Data { public int attacksPlayedThisTurn; }   // 每实例独立计数
    public override PowerType Type => PowerType.Buff;
    public override PowerStackType StackType => PowerStackType.Counter;

    protected override object InitInternalData() => new Data();

    // 打出杂耍时（可能本回合已打过攻击牌）：从 History 回溯初始化，保证"先出攻击牌再出杂耍"也正确
    public override Task AfterApplied(Creature? applier, CardModel? cardSource)
    {
        GetInternalData<Data>().attacksPlayedThisTurn =
            CombatManager.Instance.History.CardPlaysStarted.Count(e =>
                e.CardPlay.Card.Type == CardType.Attack &&
                e.CardPlay.Player == base.Owner.Player &&
                e.HappenedThisTurn(base.CombatState));
        return Task.CompletedTask;
    }

    // 每打出一张本玩家的攻击牌：计数 +1；恰好第 3 张时闪亮并按层数复制到手牌
    public override async Task BeforeCardPlayed(CardPlay cardPlay)
    {
        if (cardPlay.Card.Owner != base.Owner.Player || cardPlay.Card.Type != CardType.Attack) return;
        GetInternalData<Data>().attacksPlayedThisTurn++;
        if (GetInternalData<Data>().attacksPlayedThisTurn == 3)
        {
            Flash();
            for (int i = 0; i < base.Amount; i++)
            {
                CardModel card = cardPlay.Card.CreateClone();
                await CardPileCmd.AddGeneratedCardToCombat(card, PileType.Hand, base.Owner.Player);
            }
        }
    }

    // 己方回合结束：清零
    public override Task AfterSideTurnEnd(PlayerChoiceContext choiceContext, CombatSide side, IEnumerable<Creature> participants)
    {
        if (!participants.Contains(base.Owner)) return Task.CompletedTask;
        GetInternalData<Data>().attacksPlayedThisTurn = 0;
        return Task.CompletedTask;
    }
}
```

**关于"全局计数变量"的澄清**（回应需求描述）：

- 计数**并非全局变量**，而是 `JugglingPower` 的 private 嵌套类 `Data.attacksPlayedThisTurn`，**每个 buff 实例一份**。
- 用户观察到的"先打一两张攻击牌再打杂耍，仍能正确复制第三张"的原因：`AfterApplied` 从 `CombatManager.Instance.History.CardPlaysStarted`（战斗历史）回溯初始化，把已打的攻击牌数补进新实例。
- 因此**"本回合已出攻击牌数"是一个全局可重算的语义值**：用与 `AfterApplied` 完全相同的谓词实时统计 History 即可得到与任何 buff 实例内部计数一致的数值（多实例时各实例也一致，因为它们都从同一 History 回溯）。

### 1.3 History 与"本回合"语义

- `CombatManager.Instance.History` 类型 `CombatHistory`：`CardPlaysStarted => Entries.OfType<CardPlayStartedEntry>()`。
- `CardPlayStartedEntry`：`CardPlay`（含 `Card.Type`、`Card.Player`、`Card.Owner`）+ 继承 `CombatHistoryEntry`。
- `CombatHistoryEntry.HappenedThisTurn(ICombatState? state)`：要求 RoundNumber、CurrentSide 与当前一致，且**所有玩家的 TurnNumber 都与记录时一致**才返回 true。
- 推论：玩家回合结束、进入敌人回合或新回合后，旧攻击牌条目的 `HappenedThisTurn` 立即为 false → **用 History 实时统计时"本回合计数"自动归零**，无需自己维护清零逻辑，与 `AfterSideTurnEnd` 清零后的显示一致。
- 同类先例（游戏内其它卡/能力用同一模式）：`LethalityPower`、`Normality`、`EchoFormPower`、`RingingPower`、`NostalgiaPower`、`SmoggyPower` 均以 `History.CardPlaysStarted.Count/Any(... + HappenedThisTurn(...))` 统计"本回合出牌"。

## 3. 数据源方案对比（显示"本回合攻击牌数"）

| 方案 | 做法 | 优点 | 缺点 |
|---|---|---|---|
| **A. History 实时统计（推荐）** | 与 `AfterApplied` 相同谓词：`History.CardPlaysStarted.Count(e => e.CardPlay.Card.Type==Attack && e.CardPlay.Player==Owner.Player && e.HappenedThisTurn(CombatState))` | 纯公共 API、无语义分叉、回合边界自动归零、多实例天然一致 | 每次刷新 O(n) 遍历（战斗内条目数很小，可忽略） |
| B. 反射读 internal data | `AccessTools.Field(typeof(JugglingPower), "Data")` + `attacksPlayedThisTurn` | 直接读到 buff 内部值 | private 嵌套类 + 字段名属实现细节，版本升级脆弱；与 UI 语义无差别收益 |
| C. 自维护计数器 | patch `BeforeCardPlayed`/`AfterSideTurnEnd` 维护全局计数 | 无需 History | 与游戏逻辑分叉风险（如回放/联机 checksum、复制牌、回合边界），无必要 |

**推荐 A**：显示值即"游戏语义下的本回合攻击牌数"，永远与 buff 行为一致。

## 5. 版本兼容性关注点（v0.111.0 实测）

- `NPower.RefreshAmount` 为 private 实例方法 → Harmony 用字符串名或 `AccessTools` 定位（TwoAmountPowers 先例 `[HarmonyPatch("RefreshAmount")]`；RitsuLib 先例 `new(typeof(NPower), "RefreshAmount")`）。
- `NPower._ExitTree`、`JugglingPower.BeforeCardPlayed` 均为 public 方法，可用 `nameof`。
- 游戏每次更新需复查：① 三个 patch 目标签名；② `power.tscn` 中 `%AmountLabel` 坐标/字号（右上角布局常量依赖它）；③ `JugglingPower` 的 `AfterApplied` 谓词是否仍为"攻击牌+本回合+本玩家"。
- 与其他 mod 共存：BaseLib TwoAmountPowers 与 RitsuLib ExtraCornerAmountLabels 都挂在 `NPower.RefreshAmount` Postfix 上（各自检查自己的接口），互不干扰；本 mod 同样只对 `JugglingPower` 生效，冲突面极小。
