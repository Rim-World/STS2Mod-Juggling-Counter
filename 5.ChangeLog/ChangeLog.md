# 版本日志索引（ChangeLog.md）

本目录按版本分片记录变更，规则见根目录 `AGENTS.md`：

- 文件名 `001-<版本>-<YYYY-MM-DD>.md`，编号三位递增，按时间顺序在最前。
- 每份文件最多记录 10 个小版本，写满后另起 `002-...` 续写。
- 每条版本记录必须含七字段：版本号 / 时间戳 / 开发人员反馈 / 实装更改概括 / 简略技术细节 / 失败经验或实验教训 / 提交编号。
- 面向使用者的单文件更新日志在仓库根目录 [CHANGELOG.md](../CHANGELOG.md)，两者内容分工不同。
